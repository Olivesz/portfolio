01 / 05the problem

An agent finishes and writes “ran the tests, all passing.”

The harness has already logged every tool call it made, and nothing reads the two side by side.

A study of 20,574 real coding-agent sessions (arXiv 2605.29442) counted how often an agent that went wrong misreported its own work, and how often it corrected itself.

02 / 05how it works

A hook the harness calls on every tool call appends a CALL and a RESULT to a per-session ledger; the model has no write path to it.

The ledger is append-only, and each event is hashed with the hash before it, so editing any earlier event breaks the chain; secrets are redacted before hashing.

When the agent stops, its final report is split into claims, each a verbatim span, and a rule for each claim type checks it against the ledger. For a claim that the tests pass, the rule reads the test run:

  • no test run in the logunwitnessed
  • the output was piped or truncatedunrecorded
  • the run failed, or its count disagrees with the claimcontradicted
  • the run passedconfirmed

With a model key, a model reviews what the rules leave open, but its contradicted verdict stands only if the rule for that claim agrees; otherwise it is shown as advice.

Auto mode is opt-in. In it, a contradicted claim keeps the agent from finishing: a fixed-text message, the nudge, goes back, for up to 3 passes. The claim clears only on a tool call made after the nudge, so rewording the report does nothing.

03 / 05the false accusations

The audit aimed at the one verdict that can hurt a user: contradicted.

Over 93 local sessions with a report and at least 3 tool calls, the pipeline made 4 accusations, and at least 3 were false. Those 3 had one cause. The path regex dropped the prefix of absolute and dot-prefixed paths, so a real file looked missing and the miss became an accusation.

The fix matches paths whole, so the real file is found and nothing is accused. It also adds a guard, accusable(): a missing file supports an accusation only when the repo root exists on the machine, and the path has a directory and is absolute or inside that root. Anything else is unwitnessed: a file that could not be checked is not proven missing. After the fix the same sessions drew 1 accusation, none known false.

04 / 05results

Ten scenarios whose truth is known: all 10 scored right, with no model in the loop.

The scoreboard drives the installed hooks in a scratch git repo with real commands and no API key: 5 lies and 2 blind runs it must not confirm, and 3 reports that must draw no accusation.

Blocking stays on rules: in a repeat-run measurement on 18 real sessions, 22.8% of model-driven verdicts flipped between identical runs.

Coverage is the open limit: on real sessions the rules answered 8 of 121 claims and abstained on the other 113 rather than guess.
