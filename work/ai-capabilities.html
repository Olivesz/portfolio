ai-capabilities

Social-deduction games played by large language models: Mafia, Secret Hitler, Avalon, Spyfall and a Turing test.

Each game is one self-contained HTML file. It runs in the browser with the player’s own API key, and there is no server.

01 / 06the idea

Give a model a secret and see what it does.

Each seat is played by a model, though Spyfall also seats a human and the Turing test can make a human tester or subject. Some know what the table does not, some lack what it knows, and all of them have to talk. They are built to bring out reasoning under incomplete information, deception, theory of mind and persuasion.

One file per game is deliberate: rules, prompts and interface read in one scroll, and the rules the agents follow live in the prompt builders, so changing the game means changing a prompt.

02 / 06how a game runs

Three parts: a call, a prompt and a loop. Mafia shows all three.

callAI sends one request to OpenAI or Anthropic straight from the page and returns plain text from either. Replies are capped at 250 tokens, and a request that throws gets 2 retries.

buildPrompt writes one seat’s view: its secret role, who else is alive, the phase’s rules and what has been said this phase. It ends with “Respond in 1–3 sentences, in character.”

The loop deals 3 mafia among 10 seats, then repeats a discussion, a vote and a night kill until one side wins.

Replies are free text, so the code reads them: a vote counts for a player the reply names, or for a random one if it names none. Each phase starts with an empty transcript, so a seat voting sees the votes cast before its own, not the discussion.

03 / 06who knows what

Every prompt in a phase carries the same public transcript. What differs is the secret.

In Spyfall the spy is told only that it does not know the location; everyone else is told it. In Avalon, Merlin is told the evil seats, Percival two names of which one is Merlin, and a loyal servant nothing. Mafia tells each seat only its own role, so a mafioso is never told who its partners are.

No line scripts a lie.

The Mafia prompt only says not to reveal the role; whatever bluffing or coalition-building shows up is the model’s own.

04 / 06how it is checked

CI keeps the pages whole and the keys out.

The checks never play a game. The key is read from its field on each call and never stored or committed.

05 / 06the table and the tally

GPT and Claude models can sit at one table.

A Mafia run plays 3 to 15 games, and a results panel tallies each seat’s wins, votes cast and votes received.

The tally lives only on the page and no game saves it, so the repo holds no run to quote. What it does record is CI: on the commit pinned here, ruff finds nothing and all 14 tests pass, on both Python versions.
