01 · the situation

A grid with one rule

Wireworld is a grid of square cells. Each cell is in one of 4 states: empty, wire, an electron’s head, or its tail.

Every tick, all cells change at once, and each one looks only at its 8 neighbours. Empty cells never change. The other states follow a cycle.

The threshold is the interesting part. Here it is on one wire cell, with its neighbours lit one at a time.

Keep that third case in mind: step 03 builds on it.

The first thing the rule gives you for free is motion. Put a head on a wire with its tail behind it, and the pair moves one cell per tick.

So the rule gives you signals and a clock. What it does not give you is everything else a computer needs.

02 · the idea

Two parts and a clock

NAND can build any logic, and a clocked flip-flop can hold a bit. So the whole machine needs only two parts.

First show, in the raw rule, that logic and memory both exist there: a NAND cell, and a loop that keeps a bit. Then stop wiring by hand: put every signal on one clock, latch it in a flip-flop each cycle, and let the NAND logic settle in between.

The memory loop is not that flip-flop. It has no data input and no enable: set writes a 1, clear erases a stored 1. The CPU’s flip-flop copies its input on each clock edge; compiled to the rule, it is a NAND multiplexer feeding a loop exactly one clock long, checked on its own (chapter 05).

Logic and memory checked in the rule, then one clock for everything built from them.

03 · the build

From a wire up

Each step is made from the ones before it. Steps 01 to 05 run cell by cell in the rule; from step 06 on, the parts are NAND gates and clocked flip-flops, wired into one netlist.

step 01 · diode

A diode lets a pulse through one way

Fig 4 showed a junction pushing copies back up its inputs. A diode stops them. It is a short wire that splits around a small bridge and joins again.

The memory loop in step 05 uses one of these, turned upright, as the left edge of its loop.

step 02 · or

OR comes free

Bring two wires to either side of one cell. One arriving head or two, either way the cell fires. That is OR, with nothing added.

step 03 · saying no

Suppression: three heads make a no

XOR needs a no: two inputs that are each a yes must cancel. The only no in the rule is a crowd, so the layout makes one. Input a splits into two lanes that touch the junction; b brings one more.

Every part that inverts, from here up, is built on this crowd.

step 04 · nand

NAND: suppression with a clock

Suppression needs a third head. Give the junction a clock, and that third head arrives every lap. A clock loop drops one pulse into the junction’s top-left port. Inputs a and b come in at two other corners, timed to arrive on the clock’s tick; the output leaves from the fourth.

NOT comes with it: send one signal into both inputs. No pulse lets the clock through; a pulse brings two heads to join it, so the output is the opposite of the input.

step 05 · memory

Memory: a bit that circles

A bit can’t sit still, so it is stored as an electron going round a loop. The loop’s left edge is the diode from step 01: a set launches copies both ways round the corner, and the diode kills the one going the wrong way. A tap on the bottom edge reads a copy every lap.

Clearing it uses suppression again. One cell on the right edge, J, is the only one a two-lane clear wire touches. Time the clear so its two heads reach J as the stored bit does, and J sees three.

The raw-rule build stops here. Wiring Wireworld gates straight into each other hits a wall (chapter 04), so from here up the CPU is a netlist of two parts, NAND gates and clocked flip-flops, simulated gate by gate on one clock: every signal is latched once per cycle, and the NAND logic settles in between. The netlist assumes each NAND and each flip-flop is a verified Wireworld gadget.

step 06 · gates from nand

Every other gate is NANDs

Each box below is one NAND gate. It is filled green when its output is on; a wire is cyan when it carries a signal. The small square at the right end is the output, not a gate.

step 07 · flip-flops, registers, ram

Flip-flops wait for the clock

In the netlist a flip-flop is a part with an input d, a load line and the clock. On each clock edge it takes d, and between edges it holds: it is edge-triggered. That is what the loop of step 05 cannot do: it has no d to copy.

step 08 · the bus

One bus, one talker per step

The registers share one 8-lane bus. In each clock cycle, exactly one part drives it and one or more load from it. A ring counter steps through T1 to T6, and a grid of gates turns each step and opcode into those enables. Every instruction starts with the same fetch: T1 puts the program counter on the bus, T2 counts it up, T3 loads the instruction.

Each instruction takes up to 6 of these steps, three to fetch and up to three to execute.

step 09 · the alu

The ALU is eight adders in a row

A full adder adds two bits and a carry, from the gates in step 06: the sum is a XOR b XOR carry-in, and the carry out is set when two or more of a, b and carry-in are set. Chain eight, and each passes its carry to the next bit up. To subtract, an XOR flips every bit of b and the first carry-in is set.

step 10 · sap-1

SAP-1 runs Fibonacci

Put it together as SAP-1, the textbook Simple-As-Possible teaching CPU: a program counter, an address register, the RAM, an instruction register, A and B, the ALU, an output register, and the control grid, all on the one bus. The machine has 8-bit data, 4-bit addresses, 16 words of memory. The program, drawn beside the machine below, prints a, adds the last two numbers, shifts them along, and loops until the sum no longer fits in 8 bits.

04 · what broke

Gates that failed when composed

The first plan was to wire gates straight into each other, the way the project page’s own AND is built.

It hit a wall. A long lead on one input corrupted the other, and the wires between gates carried signals backward until they oscillated. The AND shows why: it is built as (a OR b) minus (a XOR b), with a diode on each input, and three heads have to meet on one tick at the end of long, hand-matched paths.

Now make one lead longer. A wire carries a pulse one cell per tick, so a lead one cell longer delivers a’s pulse one tick late, and the heads that were tuned to meet no longer do.

Silicon has the same hazard, and the same fix. Latch every signal in a flip-flop once per clock, and let the logic between them settle before anything reads it.

The memory loop carries the same lesson inside it. Its clear only works on one tick.

The repo’s own note gives the fix: only send a clear when a bit is stored. In the netlist, clear is part of the flip-flop’s clocked update, so its timing is never left to the wires.

The hand-built cells only work on the tick they were built for; the netlist gives every part the same clock.

05 · results

Every rung has a check that runs

The NAND cell and the memory loop pass in the rule; the gates and modules pass at netlist level; five real programs run against their expected output. Compiled to the raw rule, a full adder, a 4-bit counter and a D flip-flop match the netlist on every clock; the whole CPU is not compiled yet.

A larger SAP-2 runs on the same two parts: 18,895 NAND gates and 2,118 flip-flops, a stack and 256 bytes of memory, the memory built from flip-flops too. It runs multiply, divide, GCD, primes and bubble sort.

In Conway’s Life, the same project builds gates from glider collisions. That is a separate build; the CPU does not run on it.
